Install Kage Eyes

Minimal cyan eyes for the Waveshare ESP32-S3 Touch AMOLED 1.8.

Flash it

  1. Use Chrome or Edge on a desktop computer and connect the board with a data-capable USB-C cable.
  2. Click Install and select USB JTAG/serial debug unit.
  3. For a clean replacement of Pocket Tank, choose Erase device.
Use Chrome or Edge on desktop.This installer needs HTTPS (or localhost).

On the screen

Tap anywhere to cycle: Normal → Happy → Angry → Surprised → Sleepy → Look left → Look right. Normal also blinks automatically.

Press and hold the screen to open Settings. Tap selects an item; press and hold confirms it. Wi‑Fi setup creates a temporary local network named Kage-Eyes-Setup; join it and open 192.168.4.1 to enter your home Wi‑Fi details. Those details are stored only on the board, never on GitHub.

Once connected, choose Mise à jour to install the current published firmware over Wi‑Fi.

If the board is missing

Close serial monitors, unplug it, then hold BOOT while reconnecting USB. Try the install again.
